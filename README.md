# Clickapp — Edición Comunidad Gratuita

Controla tu Mac desde tu iPad o iPhone por Wi-Fi local.

## Descargas

- **macOS (Apple Silicon / Intel):** descarga `Clickapp-Mac-Installer.dmg` desde [Releases](https://github.com/zarz-is/clickapp-releases/releases/latest) y arrastra **Clickapp.app** a **Aplicaciones**.
  - En el primer inicio: *clic derecho → Abrir* (o *Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente*) y concede permiso de **Accesibilidad**.
- **iPadOS / iOS (AltStore / SideStore / Sideloadly):** descarga `Clickapp-iPad-iOS-Demo.ipa` desde [Releases](https://github.com/zarz-is/clickapp-releases/releases/latest) o añade esta fuente en AltStore/SideStore:
  - `https://raw.githubusercontent.com/zarz-is/clickapp-releases/main/altstore-source.json`
  - Requiere activar *Ajustes → Privacidad y seguridad → Modo de desarrollador* en el iPad/iPhone.
